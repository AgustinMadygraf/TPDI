## Formato de ADR

Los ADRs siguen el formato:

```
ADR-NNN-titulo-descriptivo.md
```

Cada ADR incluye:
- **Contexto**: La situación que motiva la decisión
- **Decisión**: La opción seleccionada y justificación
- **Consecuencias**: Positivas y negativas de la decisión
- **Alternativas rechazadas**: Otras opciones consideradas
